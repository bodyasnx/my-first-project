# VXE R1 Pro Max — лендінг

Навчальний лендінг ігрової миші VXE R1 Pro Max. Проєкт зібрано на HTML, CSS і JavaScript; частину стилів (кнопки та секція «Переваги») переписано через Tailwind CSS.

## Посилання

- **Живий сайт (Netlify, автодеплой з гілки `main`):** https://vxe-r1-landing.netlify.app
- **Дзеркало на GitHub Pages:** https://bodyasnx.github.io/my-first-project/
- **Репозиторій:** https://github.com/bodyasnx/my-first-project
- **Figma-макет:** не створювався: практичні з Figma пропущено.
- **Тестування:** тест-кейси та журнал дефектів — у файлі [TESTING.md](TESTING.md).

## Технології

- **HTML5** — семантична розмітка, атрибути доступності (`aria-*`, `label for`), теги SEO та Open Graph.
- **CSS + Tailwind CSS 4** — стилі, адаптивна верстка, світла й темна теми; збірка через `npm run build:css` (з мініфікацією).
- **JavaScript** — DOM, валідація форми, `fetch` до API, `IntersectionObserver` для підсвічування меню, `localStorage` для теми.
- **Node.js + Express** — локальний сервер API (`server/`): віддає проєкти й приймає повідомлення з форми.
- **PWA** — `manifest.json`, іконки 192/512 (зокрема maskable) і service worker `sw.js` зі стратегією «спершу мережа»: сайт можна встановити як застосунок і відкрити без інтернету.
- **Netlify** — хостинг з автоматичним деплоєм після кожного `git push`.

Сервер API працює лише локально, тому на опублікованому сайті секція «Мої проєкти» та форма показують повідомлення про недоступність сервера. Для повної роботи запустіть `node server.js` у теці `server` і відкрийте сайт через Live Server.

## Tailwind CSS чи звичайний CSS

Tailwind зручніший тим, що стилі пишуться прямо в розмітці: не потрібно вигадувати назви класів і перемикатися між HTML та CSS, а адаптивність і стани додаються префіксами `md:`, `lg:`, `hover:`. Звичайний CSS зручніший для читабельності й повторного використання: клас `.card` описується один раз, а в Tailwind довгий рядок класів доводиться повторювати для кожного елемента (або виносити через `@apply`). Tailwind також потребує Node.js і кроку збірки, а звичайний CSS працює без налаштувань; у нашому проєкті це дало, наприклад, конфлікт назви класу `container` з утилітою Tailwind.
